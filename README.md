# ماشین حساب ساده (Simple Calculator)

یک برنامه ماشین حساب ساده و زیبا ساخته شده با Flutter.

## ویژگی‌ها

- جمع، تفریق، ضرب، تقسیم
- رابط کاربری ساده و زیبا
- پشتیبانی از اعداد اعشاری
- دکمه پاک کردن و بازگشت (Backspace)

## نحوه استفاده

### برای تست در دستگاه:
```bash
flutter run
```

### برای ساخت APK:
```bash
flutter build apk --release
```

### برای ساخت APK با حجم کمتر:
```bash
flutter build apk --split-per-abi
```

APK در مسیر زیر ایجاد می‌شود:
```
build/app/outputs/flutter-apk/app-release.apk
```

## نیازمندی‌ها

- Flutter SDK
- Android SDK
- Java Development Kit (JDK)
